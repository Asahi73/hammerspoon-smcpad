# hammerspoon-smcpad

**SMC-PAD Pocket**（16パッドのMIDIパッドコントローラ）を macOS の「左手デバイス」にする
Hammerspoon 設定。パッドにアプリのフォーカス・ウィンドウ配置・デスクトップ操作を割り当てる。

同じアプリのウィンドウを複数開いているときは、そのアプリのパッドを続けて押すと
**ウィンドウを順に巡回**する。**別デスクトップ（操作スペース）にあるウィンドウにも移動できる。**

## 構成

| パス | 内容 |
|------|------|
| `hammerspoon/init.lua` | 本体（Luaコード） |
| `install.sh` | シンボリックリンクを貼るスクリプト |

## セットアップ

```sh
git clone https://github.com/Asahi73/hammerspoon-smcpad.git ~/hammerspoon-smcpad
cd ~/hammerspoon-smcpad
./install.sh
```

`install.sh` は `~/.hammerspoon/init.lua` へのシンボリックリンクを作成する。
既存ファイルがある場合は `.bak` に退避してから貼り直す。
その後 [Hammerspoon](https://www.hammerspoon.org/) を起動する（未導入なら `brew install --cask hammerspoon`）。

### 必要な権限（初回のみ）

**アクセシビリティ**: システム設定 → プライバシーとセキュリティ → アクセシビリティ →
Hammerspoon をオン。ウィンドウ操作・スペース移動・クリック送出に必要。

## 割り当て

パッドの並びは MPC／ドラム式で、**ノート36が左下**・行ごとに上へ上がる。
手前（下段）ほど使用頻度の高い開発系、奥（上段）ほど画面全体に効く操作。

```
上段  [48 デスクトップ←] [49 デスクトップ→] [50 MissionControl] [51 通知センター]    ← 画面/スペース
3段目 [44 左半分]        [45 右半分]        [46 最大化]          [47 ウィンドウ巡回]  ← ウィンドウ操作
2段目 [40 Slack]         [41 ブラウザ]      [42 Claude]          [43 メモ]            ← 連絡/情報
下段  [36 VSCode]        [37 PyCharm]       [38 cmux]            [39 Sourcetree]      ← 開発
```

### 各アクションの挙動

- **アプリのパッド**: 未起動なら起動、起動中なら前面へ。**すでに最前面なら、同じアプリの
  次のウィンドウへ巡回する**（最小化されていれば復帰、別デスクトップならそこへ移動して表示）。
  ウィンドウはID順で巡回するので、押すたびに順番が入れ替わることはない。
- **ウィンドウ巡回（47）**: 最前面アプリのウィンドウを巡回する。アプリを問わず使える。
- **左半分/右半分/最大化**: 最前面ウィンドウを、そのウィンドウがいる画面の作業領域
  （メニューバー・Dockを除く）に合わせて配置する。
- **デスクトップ前/次**: `hs.spaces` で隣のスペースへ移動する。合成キー ⌃←/⌃→ は macOS が
  無視するため使えない。2つ以上デスクトップがあるときに有効。
- **通知センター**: 今カーソルがいるモニターのメニューバー右端（時計）をクリックして開く
  （複数モニター対応）。クリック後はマウス位置を元に戻す。

## カスタマイズ

- **パッド**: `PAD_ACTION` のノート番号にアクションを書く。
- **アプリ**: 先頭の `APPS` を編集する。アプリは **bundle ID を優先、無ければアプリ名**で
  解決するので、アプリ名の言語設定やリネームに強い。bundle ID の調べ方:

  ```sh
  osascript -e 'id of app "Slack"'
  ```

  そのMacに入っていないアプリのパッドは、押してもログを出すだけで他に影響しない。
- **別のデバイスを使う**: `DEVICE_MATCH` をデバイス名（部分一致）に、`PAD_ACTION` の
  ノート番号を実機に合わせて書き換える。

設定変更後は Hammerspoon コンソールで `hs.reload()` を実行する。

### MIDIの実値を調べる

パッドのノート番号・デバイス名を知りたいときは、冒頭の `DEBUG = true` にして `hs.reload()` し、
パッドを押してコンソールの `[MIDI]` ログを見る。確認後は `DEBUG = false` に戻す。

参考: SMC-PAD Pocket は **ノート 36〜51 / MIDI ch9**（実機確認済み）。ベロシティ対応。

## 別デスクトップのウィンドウについて（macOSの制約）

macOS は「今表示しているデスクトップ以外のウィンドウ」をアプリに問い合わせさせない。
Hammerspoon のドキュメントにも `hs.window.allWindows()` は
*"can only return windows in the current Mission Control Space"* と明記されている。

そのため本設定では `hs.window.filter` に**一度見たウィンドウを覚えさせ続ける**ことで、
別デスクトップのウィンドウにも移動できるようにしている（`forceRefreshOnSpaceChange` と
`keepActive()`）。この結果、次の性質がある。

- **一度でも表示したデスクトップのウィンドウは、以降ずっと巡回対象になる。**
- Hammerspoon の起動より前から別デスクトップに置きっぱなしのウィンドウだけは、
  そのデスクトップを一度表示するまで捕捉できない（表示した時点で登録される）。
  Hammerspoon はログイン時から常駐しているので、普段使いでこれが表に出ることはほぼ無い。
