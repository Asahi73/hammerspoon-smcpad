# Macエンジニア向け設定

右⌘ を Hyper キーとして使い、アプリ切替やクリップボード履歴などをキー1つで呼び出す Hammerspoon 設定。
macOS を日常的に使用するエンジニアを対象とする。Karabiner-Elements は不要である。

## キーの方針

Hyper キーには右⌘ を使用する。右手の親指で押さえるため、割り当ては左手のキーを中心とする。

| 押しやすさ | キー | 理由 |
|---|---|---|
| ◎ | 左手のキー全般、Space | 左右の手で分担でき、指に無理がない |
| ○ | 右手のホーム段（H J K L） | 指がホームポジションのまま押せる |
| ✕ | 右手の下段（N M , . /） | 親指と指が干渉する |

Caps Lock には触れないため、Caps Lock による入力ソースの切替等の既存設定と競合しない。

## 機能

| キー | 動作 |
|---|---|
| 右⌘ + E | エディタ（VS Code） |
| 右⌘ + T | ターミナル（Ghostty → iTerm2 → ターミナル の順に探す） |
| 右⌘ + B | ブラウザ（Chrome → Arc → Safari の順に探す） |
| 右⌘ + S | Slack |
| 右⌘ + W | メモ |
| 右⌘ + F | Finder |
| 右⌘ + Space | コマンドパレット（URL・スニペット・シェルコマンド・アプリを検索して実行） |
| 右⌘ + V | クリップボード履歴（選択した項目を貼り付ける） |
| 右⌘ + H / L / K | 前面のウィンドウを左半分 / 右半分 / 最大化 |
| 右⌘ + Tab | 直前に使っていたアプリへ戻る |
| 右⌘ + R | ブラウザで開いているページを `[タイトル](URL)` 形式でコピー（Chrome / Arc / Safari） |
| 右⌘ を1秒長押し | 割り当て一覧を表示（離すと消える） |
| 設定ファイルを保存 | 設定を自動で再読み込み |

### 自動で動く機能

| きっかけ | 動作 |
|---|---|
| アプリが前面に来る | アプリごとに入力ソースを英数 / かなに切り替える（例: ターミナルは英数、Slack はかな） |
| 指定の Wi-Fi から切断される | VPN アプリを起動する |
| 外部モニタを接続する | 指定アプリのウィンドウを外部モニタに移し、左半分 / 右半分 / 最大化に配置する |
| スリープから復帰する | Slack を前面に表示する |
| ターミナルから `hsdone` を実行する | 直前のコマンドの成否を通知と音で知らせる |

### 長いコマンドの完了通知

Hammerspoon の `hs` コマンドを使う。初回のみ、Hammerspoon コンソールで次を実行してインストールする。

```lua
hs.ipc.cliInstall()                -- Intel Mac
hs.ipc.cliInstall("/opt/homebrew") -- Apple Silicon（/usr/local に書き込めない場合）
```

`~/.zshrc` に次の関数を追加する。

```sh
hsdone() { local s=$?; hs -c "notifyDone($s, '${1:-}')" >/dev/null; }
```

通知したいコマンドの後ろに付けて実行する。成功時は Glass、失敗時は Basso の音が鳴る。

```sh
make test; hsdone "make test"
```

- アプリのキーは、未起動なら起動、起動中なら前面に表示し、すでに前面にあれば非表示にする。
- 割り当てのないキーは、右⌘ でも通常の ⌘ ショートカットとして動作する（例: 右⌘ + C はコピー）。
  右⌘ + V はクリップボード履歴となるため、貼り付けには左⌘ + V を使用する。
- クリップボード履歴は直近30件を保持し、Hammerspoon を再起動しても残る。
  パスワードマネージャ等が記録対象外と指定したコピーは保存しない。

## 導入と復元

```sh
./hammerspoon/variants/mac-engineer/install.sh              # 導入（既存の init.lua を退避）
./hammerspoon/variants/mac-engineer/install.sh --uninstall  # 退避した init.lua を復元
```

本設定は macOS のシステム設定を変更しない。Hammerspoon を終了すると、すべての割り当てが解除される。

## カスタマイズ

`init.lua` 冒頭の変更箇所を編集する。保存すると自動で再読み込みされる。

- `APPS`: キーとアプリの対応。`bundleIDs` を上から順に試し、見つからなければ `name` で起動する
- `PALETTE`: コマンドパレットの項目。`kind` は `url` / `snippet` / `shell` のいずれか
- `CLIP_MAX`: クリップボード履歴の件数
- `CHEAT_HOLD_SEC`: 割り当て一覧を表示するまでの長押し時間（秒）
- `INPUT_BY_APP`: アプリ（bundle ID）ごとの入力ソース。`"en"` は英数、`"ja"` はかな
- `WIFI_VPN`: 切断を検知する SSID と、起動する VPN アプリ
- `MONITOR_LAYOUT`: 外部モニタ接続時に配置するアプリと位置（`left` / `right` / `max`）
- `WAKE_APP`: スリープ復帰時に前面化するアプリ

アプリの bundle ID は次のコマンドで確認できる。

```sh
osascript -e 'id of app "Slack"'
```

## 注意事項

- アクセシビリティ権限が必要である（システム設定 → プライバシーとセキュリティ → アクセシビリティ）。
- パスワード入力欄などのセキュア入力中は、macOS の仕様により右⌘ の割り当てが動作しない。
- コマンドパレットのシェルコマンドはログインシェル（zsh）で実行し、結果を画面に表示する。
- Wi-Fi の SSID の取得には、Hammerspoon への位置情報サービスの許可が必要である（macOS 14 以降）。
  許可がない場合、Wi-Fi 切断時の VPN 起動は動作しない。
- Markdown リンクのコピーは、初回に macOS がブラウザの操作の許可を求める。
- 入力ソースの切替は英数 / かなキーの入力を送る方式のため、IME の種類を問わない。
- 外部モニタ接続時の配置は、起動中のアプリの、表示中のデスクトップにあるウィンドウが対象である。
- 実機での確認事項: 右⌘ の判定、長押しでの一覧表示、貼り付けのタイミング、外部モニタ接続時の配置。
